Do you have an earlier version (0.5–0.9)? Quit the app, then install 1.0.0 over it; the library and the saved edits stay. Photographs edited with earlier versions are rendered in 1.0.0 with the open display transform, so they can look different.

Requirements for version 1.0.0

macOS 13 (Ventura) or later · a Mac with Apple Silicon or Intel. The subject mask needs macOS 14. The app does not need DaVinci Resolve.

Installation

1. Download the package and double-click it.
2. Follow the installer steps (it asks for your Mac password).
3. Open FotoAsist GC from Applications and choose where the app keeps its catalog and thumbnails. Your originals are not moved.

Open source and contributions

The source code of this version is public: github.com/gordasgdc/fotoasist-gc. The project is open to contributions through Issues and Pull Requests and is maintained occasionally. The package above is built from the source tagged v1.0.0. The open-source edition does not include GDC DRT, selective colour and skin, diffusion and bloom, photochemical film emulation, the look and cinema style libraries, or the OFX plug-in.

Status

The first open-source version. There may be limits and problems; you can report them on the project page.
