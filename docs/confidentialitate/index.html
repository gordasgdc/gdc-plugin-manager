Politică de Confidențialitate (GDPR)

Cum sunt colectate, folosite și protejate datele tale cu caracter personal, în aplicațiile și pe site-ul ecosistemului GDC.

Statutul proiectului. GDC / gordas.dev este un proiect dezvoltat independent, nu o societate comercială înregistrată. Chiar și fără obligațiile formale ale unei firme, respectăm principiile Regulamentului General privind Protecția Datelor (GDPR/UE 2016/679): colectăm strict minimul necesar, nu vindem și nu cedăm date către terți, și îți oferim control real asupra lor.

1. Cine procesează datele

Datele descrise mai jos sunt procesate direct de dezvoltatorul independent din spatele ecosistemului GDC (gordas.dev), nu de o entitate juridică separată sau de un departament dedicat de protecție a datelor. Solicitările legate de date se adresează direct prin contactul de mai jos.

2. Ce date colectăm

3. Unde sunt stocate datele

  • Local, pe dispozitivul tău — majoritatea datelor (preferințe, cache catalog, fișier de licență) nu părăsesc niciodată calculatorul tău.
  • Supabase (bază de date folosită pentru gestionarea licențelor și revocări) — stochează Machine ID, produsul licențiat și, dacă l-ai furnizat, emailul asociat.
  • GitHub — găzduiește catalogul public de produse (fără date personale) și, pentru istoricul intern de vânzări al dezvoltatorului, date minime necesare gestionării licențelor deja acordate.

4. Nu vindem datele tale

Nu vindem, închiriem sau oferim datele tale unor terți în scop de marketing. Datele colectate sunt folosite exclusiv pentru funcționarea Software-ului (licențiere, suport) și, agregat/anonimizat, pentru a înțelege ce funcționalități merită dezvoltate mai departe.

5. Cât timp păstrăm datele

Datele legate de o licență activă se păstrează cât timp licența e valabilă sau cât timp e nevoie pentru suport/istoricul de susținere financiară. Poți solicita oricând ștergerea lor (vezi secțiunea 6), cu mențiunea că ștergerea unui Machine ID dintr-o licență activă poate dezactiva accesul la produsul respectiv.

6. Drepturile tale (GDPR)

Ai dreptul să soliciți, oricând, prin contactul de mai jos:

  • Acces — ce date deținem despre tine.
  • Rectificare — corectarea unor date greșite (ex. email schimbat).
  • Ștergere — eliminarea datelor tale din evidențe ("dreptul de a fi uitat").
  • Opoziție/restricționare — limitarea modului în care folosim datele tale.
  • Portabilitate — primirea datelor tale într-un format structurat.

Răspundem solicitărilor într-un termen rezonabil, de regulă sub 30 de zile.

7. Securitate

Licențele software folosesc semnături criptografice (Ed25519) verificate local — nu un simplu cod trimis pe server. Accesul la baza de date Supabase este restricționat, iar comunicarea cu ea se face criptat (HTTPS/TLS).

8. Modificări ale politicii

Această politică poate fi actualizată pentru a reflecta schimbări reale în funcționare. Data ultimei actualizări apare în antetul paginii.
