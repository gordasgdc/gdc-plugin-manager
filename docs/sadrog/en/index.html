B · PREPARING AND RECORDING

Pick the sources.
Press Record.

Each source has its own row: a display, a window or a region; a camera; computer sound; a microphone. Nothing is mixed in the capture file — each source later lands on its own track in the editor.

What it does

Prepares a recording: lists the sources, shows permission status and runs a 3-second countdown before starting.

Why it is useful

You see at a glance what will be recorded before you start. A missing source or an ungranted permission does not surprise you at the end.

How to use it

  1. Open New recording.
  2. Add the sources you want: screen, Window, Camera, Computer sound or a microphone from Add source.
  3. Choose the destination folder and press the round record button.
Result A project with one track per source, ready to edit.

Display, window or region

You choose which part of the screen is recorded. For a region you set the rectangle; for a window you pick the app.

Why it matters

A tutorial about a single app stays clean if you record only its window.

How to use it

  1. Open the source details with the arrow on the right.
  2. Choose Display, Window or Region.
Result The capture file contains exactly what you chose, at the source resolution.

macOS permissions, in context

macOS asks for your consent to capture the screen, microphone and camera. SADROG asks only when you need them and shows their status on a dedicated page.

Why they appear

They are system protections, not app ones: without them macOS does not let any app record.

How to use it

  1. Open Permissions in the sidebar.
  2. If one is missing, grant it in System Settings › Privacy & Security.
  3. Restart SADROG if macOS asks you to.
Result Sources start without interruptions, and the microphone and camera are not requested if you do not use them.

C · FROM RECORDING TO PROJECT

Recording ends.
The project begins.

When you finish, the recording becomes an editing document with the size and frame rate you chose. You can also start an empty document, or add new recordings to an open project.

New document

Creates an editing project without a recording, with the size and frame rate you want, or receives your recordings as material.

Why it is useful

You can prepare the structure of an edit (for example 1080p at 30 fps) before you have recordings, or combine existing material.

How to use it

  1. Open New document.
  2. Pick a preset or your own size and the frame rate.
  3. Press Create document; import files into the library.
Result An auto-saved project in a folder of your choice.

Add to an existing project

From the editor, the Add menu records or imports a file and puts it at the end of the main track, in a single undo step.

Why it is useful

You continue a tutorial without starting a new one. If you cancel the recording, you are back exactly where you were.

How to use it

  1. In the editor, open Add › recording or file.
  2. Record or choose the file.
  3. The new recording appears at the end of the timeline.
Result One project with all recordings, organized in the library and on tracks.

D · EDITING IN THE VIEWER AND TIMELINE

Work directly on the image
and on the tracks.

Select an element in the viewer or on the timeline. The inspector on the right shows only the properties of what you picked, and the timeline shows which clip each effect applies to.

Tracks you control

Video, audio, title and highlight tracks. You can rename, add, lock, hide, resize and reorder them.

Why it is useful

A project with several recordings stays readable. The topmost of the video tracks is in front of the others.

How to use it

  1. Drag the handle under a track to change its height.
  2. Drag the handle left of its name to move it.
  3. Use the lock and the eye to lock or hide.
Result Track heights and order are kept when you save and reopen.

Direct selection and contextual inspector

Click an element in the viewer or on the timeline. Repeated clicks cycle through overlapping elements. The inspector changes with the element type.

Why it is useful

You do not hunt for controls in menus: what you see is what you can change, for exactly the element you picked.

How to use it

  1. Select a clip, title or highlight.
  2. Drag the handles in the viewer or type values in the inspector.
  3. Use the Scissors tool to cut and drag clip edges to trim.
Result Position, scale, rotation and opacity adjusted in place; every step can be undone.

Duplicate, drag-and-drop, undo

Elements move by dragging, and a preview shows where they will land before you let go. The clip menu also offers Duplicate. If a placement is not possible (locked track or overlap) you are told why. Every action is a single undo step.

E · SOUND

Every source,
on its own track.

Computer sound and microphone are recorded separately. In the editor you see them as waveforms, adjust them independently, and can detach a video clip’s audio into a piece of its own.

Independent sources

Each recorded audio source stays separate: you see it as a waveform and switch it on or off without affecting the others.

Why it is useful

If the microphone has noise, you fix or mute it without losing the app’s sound.

How to use it

  1. See the sources on the audio rows below the timeline.
  2. Use the row’s sound button to mute.
  3. Select an audio clip for level and fades.
Result An example with two sources: your voice-over and the app’s sound, mixed on export into a single audio track, just like the preview.

Audio separate from the image

From the Clip menu or the inspector you detach a video clip’s sound into an audio element, at the same position and with the same offset from the source. You can move, cut, delete or re-attach it.

Why it is useful

You can let the sound continue over another image, or delete just the image.

How to use it

  1. Select the video clip.
  2. Choose Detach audio from the Clip menu.
  3. Adjust volume and fades in the audio inspector; Re-attach returns it to the image.
Result Sound stays in sync with the image as long as you do not move it; it is not doubled. On re-attach, level and mute are kept, or you are told why it cannot be done.

F · VISUAL PRESENTATION

Camera, titles
and highlights.

The camera can be arranged over the screen, in a circle or a rectangle. Titles and annotations are drawn straight in the viewer and stay editable objects on the timeline.

The camera overlay

A camera clip can be placed anywhere over the screen, scaled, rotated and made semi-transparent. Circular presenter crops it into a circle, with framing, offset and outline.

Why it is useful

Viewers see you while they follow your screen — the tutorial standard.

How to use it

  1. Select the camera clip.
  2. In Circular presenter choose the corner position, framing and outline.
  3. Fine-tune in Transform.
Result The source stays untouched; you can go back to a rectangle at any time.

Effects attached to a clip

A highlight, frame or arrow attaches to a specific clip. Its band appears on the clip, and the inspector controls the selected effect.

Why the target matters

An effect applied to the wrong clip does not show at the intended moment. The button, the drawing and the inspector use the same target, and the timeline clearly shows the targeted clip.

How to use it

  1. Select the target clip.
  2. Pick a shape from the toolbar (rectangle, circle, line, arrow, freehand) and draw in the viewer.
  3. You can also drag an effect over a clip.
Result Several effects can run at the same time, on different clips.

Titles and text styles

Titles have alignment, bold, italic, underline, outline, colour, background, several lines, and appear and disappear effects.

Why it is useful

You mark tutorial steps and feature names without external apps.

How to use it

  1. Press Aa in the toolbar.
  2. Type the text in the viewer.
  3. Choose style and effects in the inspector.
Result An editable title that stays an object on the timeline.

G · MOTION AND STRUCTURE

Markers, ranges,
animations and transitions.

Markers help you find your way, In/Out sets what is exported, and animations and transitions give the edit its rhythm.

Markers, In/Out and freeze frame

Named markers are visible on the ruler. In and Out set the exported range (the “Only between In and Out” option). Freeze frame extends the image from the cursor.

Why it is useful

You find your way around a long edit and export just a fragment.

How to use it

  1. Put the cursor and use Set In at cursor (and Out).
  2. Press the freeze tool for a still frame.
  3. Export only the range from the export window.
Result An exported fragment with a known duration.

Animations and transitions

Clips, overlays and titles can be animated between two states, with linear, ease-in or ease-out motion; you have multiple keys and easing curves. Between clips you can put a cross dissolve, with explicit length limits. Cutting or freezing keeps exactly what the animation showed before and after.

About the cursor and Foreground Window

Cursor-following zoom and click highlights need metadata recorded during capture: cursor position and clicks, and the foreground window. These are optional and off by default; the keyboard is not read. They cannot be inferred afterwards from an arbitrary video.

H · EXPORT AND KEEPING THE PROJECT

A clear export.
A project that is never lost.

Export has a simple mode with presets and an advanced mode with controls for size, frame rate, codec and quality. The summary in the window describes exactly the file you will get.

Simple export

Pick the preset, the range (whole project or only between In and Out) and the name. The summary shows the resulting size, frame rate, codec and sound.

Why it is useful

You get a good file without knowing technical terms. The default name contains the project name and the date.

How to use it

  1. Press Export.
  2. Choose preset and destination.
  3. Press Export in the window.
Result A video file in the chosen folder. The destination is protected, and a cancelled export leaves no partial files.

Advanced export

Controls for size (including 4K and custom values), frame rate, codec (H.264, HEVC), quality, video rate, keyframes and audio rate. Presets can be saved.

Copy without processing vs re-encode

Copy without re-encoding keeps source quality, but is refused when the project requires processing (for example titles, effects or mixing) — it never degrades silently. Processed and compressed re-encodes with loss. There are also ProRes master and lossless frame sequence + WAV.

How to use it

  1. Switch to Advanced.
  2. Pick the mode, then size, frame rate and codec.
  3. Check the summary at the bottom before exporting.
Result The file has exactly the values in the summary; size and range are checked after export.

Archiving the project and moving it

Archive: project + media makes a self-contained copy with relative paths, so it opens anywhere and finds its media even if the folder is moved. The originals do not change. If media is missing, archiving refuses and says what is missing; a missing clip can be relinked with Relink file…. A stopped archive leaves no partial archive.

I · INSTALL, TRIAL AND ACTIVATION

Download.
Request the trial. Get approved.

SADROG installs like any Mac app. Editing and saving work right away, without activation; new recording and export need activation.

Requirements

  • macOS 15 or newer
  • Mac with Apple Silicon
  • Distribution signed with Developer ID and notarized by Apple
  • About 5 MB download

Steps

  1. Download the file SADROG-1.0.1.dmg and open it.
  2. Drag SADROG to Applications and launch it.
  3. Open Activation in the sidebar, choose Full trial · 5 days, fill in your name and e-mail and send the request.
  4. The request is approved manually by the developer. Once approved, SADROG picks up the right by itself.

J · FAQ AND SUPPORT

Short answers,
limits stated openly.

If you do not find the answer here, open the manual or write to us on the project page.

What permissions does SADROG ask for, and why?

Screen Recording to capture, Microphone for microphone sound and Camera for the camera. The last two are requested only when you add such a source. The keyboard is not read.

A source is missing (camera, microphone, display). What do I do?

Check in Permissions that access is granted and the device is connected. Then add it from the Add source menu. Test sources marked SIMULATION appear only in the verification build.

I moved the project’s media. What happens?

The project marks its missing files; use Relink file… to point to them again. For a project that must travel, create an archive with media: it opens anywhere.

Why can’t I copy without processing?

Copying without re-encoding requires that the project needs no processing. Titles, effects or mixing make it impossible, and SADROG refuses instead of silently degrading quality. Choose “Processed and compressed” or ProRes.

How does SADROG update?

From the app: Check for updates…, or download the latest file from this page. Updates install without deleting your projects.

What data is sent at activation?

Name and e-mail for the reply, the computer name (optional), the option chosen, language, version and the Mac’s identifier. No recordings, projects or captures are sent.

Where do I find the diagnostic log?

SADROG writes a local log at ~/Library/Logs/SADROG.log (no passwords or file contents). You can attach the file when asking for support.

What are the limits of version 1.0?

It runs only on Apple Silicon and macOS 15+. Cursor and foreground window are recorded only if you enable the option before capture. The Audio Unit plug-in library depends on the plug-ins you installed. Features announced for the future are not presented here as existing.

Where do I ask for support?

On the project page: github.com/gordasgdc/sadrog/issues. For activation, from the app (WhatsApp or e-mail buttons).
