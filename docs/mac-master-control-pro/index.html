Module

🌐

Rețea & TCP Tuning

Forțare 1 Gbps Full-Duplex, DNS Cloudflare/Google, buffere kernel 1MB, la un click.

☁️

Cloud Manager Universal

Google Drive, Dropbox, OneDrive, pCloud, Degoo, Mega, S3, WebDAV, SFTP/NAS — montate ca disc, cu upload/download/sincronizare integrate. Detalii mai jos ⬇

🧹

Curățare & RAM

Cache DaVinci Resolve, Adobe, Xcode DerivedData, Time Machine Snapshots, purjare RAM + flush DNS.

🛠️

Tweak-uri Sistem

Finder avansat, blocare .DS_Store pe USB/NAS, Touch ID pentru sudo, Spotlight Shield pentru foldere RAW.

🧭

Rosetta 2 Inspector

Scanează /Applications pentru cod Intel, verifică starea Rosetta, elimină mediul de traducere când nu mai e nevoie.

🧩

Dependency Auto-Installer

Detectează Homebrew/Rclone/macFUSE și le instalează cu un click, fără Terminal.

☁️ Cloud Manager — motor Rclone, interfață 100% nativă

Sub capotă rulează Rclone — motorul open-source de sincronizare cloud folosit de zeci de mii de proiecte — dar TU nu vezi niciodată linie de comandă. Totul e vizual, în stilul dark/amber al aplicației.

💽

Montare ca disc real

Orice cont cloud apare ca un folder pe care îl deschizi direct în Finder/Explorer — copiezi, muți, redenumești, exact ca pe un disc extern.

📍

Locație de montare la alegere

SSD intern mic? Montezi pe orice disc extern Thunderbolt/USB-C — nu mai ocupi spațiu pe unitatea principală.

📊

Statistici live de transfer

Viteză, bytes transferați, transferuri active — actualizate la 2 secunde, direct sub numele contului.

🔎

Explorare fără montare

Răsfoiești conținutul unui cont cloud instant, fără să-l montezi — ideal pentru o verificare rapidă.

⬆️

Upload / Download direct

Încarci sau descarci fișiere și foldere întregi din aplicație, cu progres live, fără să deschizi pagina web a providerului.

🔄

Sincronizare inteligentă

Un folder local ↔ cloud, în orice direcție. Implicit non-distructiv (doar adaugă/actualizează) — oglindă exactă doar dacă bifezi explicit.
