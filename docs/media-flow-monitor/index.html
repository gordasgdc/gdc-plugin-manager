Cum se instalează & se activează

macOS
  1. Dă dublu-click pe MediaFlowMonitor.pkg — se deschide asistentul clasic de instalare Mac ("Install MediaFlow Monitor"), semnat + notarizat Apple, fără avertismente Gatekeeper.
  2. Apasă Continue → Install — aplicația se instalează automat direct în /Applications, fără să tragi nicio iconiță manual.
  3. Apasă Cmd+Shift+M pentru a arăta/ascunde panoul Dashboard Pro.
Windows
  1. Dă dublu-click pe MediaFlowMonitorSetup-x64.exe — apare wizard-ul "Install MediaFlow Monitor".
  2. Instalator nesemnat (fără certificat Authenticode încă) — Windows arată "Windows protected your PC": apasă More info → Run anyway.
  3. Continue → Install — se instalează în Program Files\GDC\MediaFlow Monitor, cu scurtături Desktop + Start Menu.
  4. Apasă Ctrl+Shift+M pentru a arăta/ascunde panoul Dashboard Pro.
  1. Aplicația pornește automat cu 15 zile de probă gratuită, fără cont sau înregistrare, pe ambele platforme.

Aplicația include 15 zile gratuite, acces complet. Pentru activare pe viață, deschide meniul aplicației (bara de meniu pe Mac, system tray pe Windows) → copiază Machine ID → trimite-l pe WhatsApp pentru activare.

Integrare ecosistem GDC
