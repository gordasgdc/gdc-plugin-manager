Panou pentru DaVinci Resolve · macOS · gratuit

Găsești sunetul. Îl asculți. Îl pui pe timeline.

Un panou de efecte sonore care stă lângă Resolve: formă de undă reală pe fiecare sunet, audiție rapidă, plasare la cursor pe pista aleasă, fără să lași editarea.

Fluxul

  1. Alege folderulAdaugi folderul cu sunete; panoul le listează cu forma de undă și durata.
  2. AscultăTreci cu mouse-ul sau apasă ▶ pentru audiție rapidă; favorite și recente la un clic.
  3. PlaseazăAlegi pista, vezi poziția cursorului, apeși Plasează. Suprapunerile sunt oprite înainte de scriere.

Ce face

Tutoriale video

Clipuri scurte, fără voce și fără text pe ecran. Interfața filmată este în română; titlurile rămân în română și în paginile în alte limbi.

Instalare și cerințe

  • DaVinci Resolve Studio 21 sau mai nou, macOS.
  • Python 3 (panoul îl verifică și arată pașii de instalare).
  • În Resolve: Preferences → General → External scripting using: Local.
  • Dublu-clic pe pachet, apoi Workspace → Workflow Integrations → SoundSFXPaste.

Limite cunoscute

  • Timeline-urile drop-frame sunt refuzate explicit.
  • Resolve nu oferă API pentru selecția clipurilor; Replace folosește selecția manuală.
  • Tragerea sunetului direct pe timeline nu este disponibilă; plasarea se face cu butonul.
