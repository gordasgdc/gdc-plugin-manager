SADROG · FOR MAC

Record.
Edit.
In one place.

SADROG captures your screen, a window, your camera and sound, then lays them on a timeline with separate tracks. Cut, arrange, add titles and highlights, and export — without leaving the app.

Who it is for

  • Screen + camera tutorials

    Show the steps on screen while your camera appears in a circle on top.

  • App demos

    Highlight buttons with frames and arrows exactly where they matter.

  • Presentations with voice-over

    The microphone stays on its own track: adjust, mute or switch it off without touching the screen.

B · PREPARING AND RECORDING

Pick the sources.
Press Record.

Each source has its own row: a display, a window or a region; a camera; computer sound; a microphone. Nothing is mixed in the capture file — each source later lands on its own track in the editor.

What it does

Prepares a recording: lists the sources, shows permission status and runs a 3-second countdown before starting.

Why it is useful

You see at a glance what will be recorded before you start. A missing source or an ungranted permission does not surprise you at the end.

How to use it

  1. Open New recording.
  2. Add the sources you want: screen, Window, Camera, Computer sound or a microphone from Add source.
  3. Choose the destination folder and press the ruby Start recording button.
Result A project with one track per source, ready to edit.

Display, window or region

You choose which part of the screen is recorded. For a region you set the rectangle; for a window you pick the app.

Why it matters

A tutorial about a single app stays clean if you record only its window.

How to use it

  1. Open the source details with Resolution details.
  2. In the source’s ⋯ menu choose Display, Window or Region.
Result The capture file contains exactly what you chose, at the source resolution.

macOS permissions, in context

macOS asks for your consent to capture the screen, microphone and camera. SADROG asks only when you need them and shows their status on a dedicated page.

Why they appear

They are system protections, not app ones: without them macOS does not let any app record.

How to use it

  1. Open Permissions in the sidebar.
  2. If one is missing, grant it in System Settings › Privacy & Security.
  3. Restart SADROG if macOS asks you to.
Result Sources start without interruptions, and the microphone and camera are not requested if you do not use them.

C · FROM RECORDING TO PROJECT

Recording ends.
The project begins.

When you finish, the recording becomes an editing document with the size and frame rate you chose. You can also start an empty document, or add new recordings to an open project.

New document

Creates an editing project without a recording, with the size and frame rate you want, or receives your recordings as material.

Why it is useful

You can prepare the structure of an edit (for example 1080p at 30 fps) before you have recordings, or combine existing material.

How to use it

  1. Open New document.
  2. Pick a preset or your own size and the frame rate.
  3. Press Create document; import files into the library.
Result An auto-saved project in a folder of your choice.

Add to an existing project

From the editor, the Add menu records or imports a file and puts it at the end of the main track, in a single undo step.

Why it is useful

You continue a tutorial without starting a new one. If you cancel the recording, you are back exactly where you were.

How to use it

  1. In the editor, open Add › recording or file.
  2. Record or choose the file.
  3. The new recording appears at the end of the timeline.
Result One project with all recordings, organized in the library and on tracks.

Recent projects and the finished recording

In the Recent list every entry has a ⋯ menu: Open, Show in Finder and Remove from Recent (it deletes no file). When a recording ends, a sheet offers Create document and open or Keep only the recording.

When the file is missing

The entry says it is missing from disk. Show in Finder does not pretend to find it: it only opens the parent folder, if there is one, and says so. For a missing project there is Locate…, to pick its new place.

How to use it

  1. Open Recent and press ⋯ on an entry.
  2. Pick what you want: open, Finder, or remove it from the list.
  3. After a recording, choose in the sheet whether a document is created.
Limits Removing from Recent does not touch files on disk. The recording stays saved even if you do not create the document.

D · EDITING IN THE VIEWER AND TIMELINE

Work directly on the image
and on the tracks.

Select an element in the viewer or on the timeline. The inspector on the right shows only the properties of what you picked, and the timeline shows which clip each effect applies to.

Tracks you control

Video, audio, title and highlight tracks. You can rename, add, lock, hide, resize and reorder them.

Why it is useful

A project with several recordings stays readable. The topmost of the video tracks is in front of the others.

How to use it

  1. Drag the handle under a track to change its height.
  2. Drag the handle left of its name to move it.
  3. Use the lock and the eye to lock or hide.
Result Track heights and order are kept when you save and reopen.

Direct selection and contextual inspector

Click an element in the viewer or on the timeline. Repeated clicks cycle through overlapping elements. The inspector changes with the element type.

Why it is useful

You do not hunt for controls in menus: what you see is what you can change, for exactly the element you picked.

How to use it

  1. Select a clip, title or highlight.
  2. Drag the handles in the viewer or type values in the inspector.
  3. Use the Scissors tool to cut and drag clip edges to trim.
Result Position, scale, rotation and opacity adjusted in place; every step can be undone.

Duplicate, drag-and-drop, undo

Elements move by dragging, and a preview shows where they will land before you let go. The clip menu also offers Duplicate. If a placement is not possible (locked track or overlap) you are told why. Every action is a single undo step.

Rectangle selection and operations on the selection

With the Select tool, drag from free space in the timeline: the rectangle selects the clips, titles, highlights and sounds it touches, across all tracks. The timeline scrolls by itself at the edge; Esc cancels the gesture, and a click in free space clears the selection. With ⇧ or ⌘ you add to the existing selection.

What you can do next

Selected items move together, keeping the distances and sync between them. Cut selected items at the playhead (⇧⌘K) cuts only what is selected and touches the playhead, not every track. Locked tracks are respected: the operation is refused as a whole, with an explanation, with no partial change. If the selection also contains main-track clips, their block is re-inserted at the nearest boundary between clips (the main track stays sequential, with no hidden overlap) and the other items move by the same distance, so their timing relationship stays identical; detached sound of moved clips travels with them. While you drag, a dashed outline shows where the block lands; when the destination is not possible (locked track, overlap, non-adjacent clips, a transition between them) the app says why and changes nothing. The move is one Undo step. With the Blade tool, a click on one of the items of a multiple selection cuts the whole selection at exactly the same instant (V1, camera, detached sound, titles); a click on an item outside the selection cuts only that item, and the vertical guide turns yellow and shows how many items will be cut. The cut is one Undo step, and a locked track refuses it as a whole. Selected items have a yellow outline with a dark edge, visible over any track colour, in both the Dark and Light themes.

How to use it

  1. Choose Select and drag a rectangle from free space.
  2. Move the selection or use Cut selected items at the playhead from the Timeline menu.
  3. Press Esc during the gesture to give up.
  4. With Blade active, a click on a selected item cuts the whole selection at the same instant.
Result One operation, one Undo step; after saving and reopening everything stays in place.

Move a cut clip to a video track, and independent titles

A clip cut from the main track can be moved to a video track above it (Move to video track (V2) in the clip menu), keeping its properties and links. It is not possible for the last clip, nor for frozen, dissolving or cursor-effect clips — and the app says why. Titles that overlap in time place themselves on separate rows and stay independent.

Inspector tabs and fine sliders

The inspector groups what you picked into exclusive tabs: Video, Sound, Time and Cursor. Only the tabs that make sense for the selection appear, and only one is open at a time. Every slider has a numeric field for exact values.

Reset

Double-click a slider (or the reset button next to the value) to return it to its neutral value, as a single Undo step.

How to use it

  1. Select a clip, overlay or sound.
  2. Pick the tab at the top of the inspector (or its keyboard shortcut).
  3. Drag the slider or type the value; double-click to reset it.
Limits A sound has no Video tab. The Cursor tab has effects only for a recording made with pointer saving on.

Customizable keyboard shortcuts

In Settings ▸ Shortcuts you see every command with its combination. Search a command, click its combination and press the key you want; you can remove a combination, return it to the default or reset everything. Combinations are kept and show up in the menus and in the hover explanations.

Conflicts

If a combination is already used, the app tells you by which command and does not duplicate it silently. Standard system combinations (such as those of the Edit menu) cannot be changed.

How to use it

  1. Open Settings ▸ Shortcuts.
  2. Pick the command, click its combination and type the new one (Esc cancels).
  3. Reset all brings the defaults back.
Limits Single editing keys (for example A, B, U) work only while you are not typing in a text field.

E · SOUND

Every source,
on its own track.

Computer sound and microphone are recorded separately. In the editor you see them as waveforms, adjust them independently, and can detach a video clip’s audio into a piece of its own.

Independent sources

Each recorded audio source stays separate: you see it as a waveform and switch it on or off without affecting the others. The headphones button next to the transport changes only the listening volume of the editor, not the clips’ level or the export.

Why it is useful

If the microphone has noise, you fix or mute it without losing the app’s sound.

How to use it

  1. See the sources on the audio rows below the timeline.
  2. Use the row’s sound button to mute.
  3. Select an audio clip for level and fades.
Result An example with two sources: your voice-over and the app’s sound, mixed on export into a single audio track, just like the preview.

Audio separate from the image

From the Clip menu or the inspector you detach a video clip’s sound into an audio element, at the same position and with the same offset from the source. You can move, cut, delete or re-attach it.

Why it is useful

You can let the sound continue over another image, or delete just the image.

How to use it

  1. Select the video clip.
  2. Choose Detach audio from the Clip menu.
  3. Adjust volume and fades in the audio inspector; Re-attach returns it to the image.
Result Sound stays in sync with the image as long as you do not move it; it is not doubled. On re-attach, level and mute are kept, or you are told why it cannot be done.

Clip speed

Any clip on the timeline can be sped up or slowed down: 0.25×, 0.5×, 1×, 2×, 4×, 6× or a custom value between 0.1× and 16×. The inspector shows the source length and the resulting length on the timeline (60 s at 6× become 10 s; at 0.5× they become 120 s). It also works on a piece obtained by cutting.

What happens to the rest

On the main track the following clips move (ripple) so no gap is left. On independent tracks nothing is moved arbitrarily: if the new length would overlap another item the change is refused and you are told why. Linked sound stays in sync with the picture, and detached sound receives the same speed. Cuts, fades, keys and effects follow the same local time.

How to use it

  1. Select the clip.
  2. In the Speed group pick a preset or type a value.
  3. Back to 1× returns the clip to its original speed.
  4. Optionally Keep sound pitch or No sound at this speed (other tracks are not touched).
Limits Slow motion repeats frames, with no motion interpolation. There is no reverse and no speed ramps. A freeze frame has no speed. Old projects open at 1×, unchanged.

Volume automation, fades and crossfade

In the Volume automation group you add points to a sound’s volume curve (values in dB; “Mute” means complete silence), drag them on the timeline or type them, jump from point to point and delete them. Fade-in and fade-out can be linear, slow-in, slow-out or an S-curve with adjustable curvature; the applied curve is drawn in the inspector. Between two independent sound items you can create a crossfade, drawn as an X, with equal gain or equal power.

Order of calculation

Source and clip volume, then automation, fades, crossfade, effects and the master volume. Each is applied once, and the master volume does not enter stems. Equal gain: levels add up to 1 — constant for the same sound on both sides, with a dip of up to 3 dB in the middle for different sounds. Equal power: power stays constant for different sounds; for the same sound on both sides the middle rises by up to 3 dB.

How to use it

  1. Select the sound.
  2. Press Point at playhead or drag a point on the curve; type level and time for exact values.
  3. Pick the fade shape in the Fade group.
  4. Crossfade with previous item creates the crossfade; its length is the real overlap of the items.
Limits A clip’s points use the clip’s local time; there is no whole-track automation. A crossfade never invents material: if the source has not enough, it is refused. A locked track cannot be changed. Esc cancels a point drag in progress (as does dragging far outside the clip); nothing is changed and no undo step is added.

Voice processing

From a source’s Effects window you can apply a preset: High-pass filter only, Clean voice, Podcast voice or Limiter only. They are built from the Apple effects that ship with macOS (high-pass filter, dynamics processor, peak limiter) through the same host as any plugin: SADROG has no DSP of its own here, and each stage appears in the chain and can be bypassed, moved, opened or deleted.

What it does NOT do

The expander in the presets conservatively lowers only very quiet passages between words; it is not intelligent noise removal and cannot tell voice from noise. The high-pass filter cuts rumble and hum below 80–90 Hz (about 11 dB one octave below the cut-off), not noise inside the voice band.

How to use it

  1. Open Effects on the microphone source.
  2. Pick a preset under Voice processing.
  3. Reset voice processing removes it without touching other plugins.
Limits Parameters cannot be automated over time. Sound is processed offline and is heard once it finishes.

Volume and fades directly on the track

With the Volume tool (timeline toolbar), double-clicking an item with sound adds a volume point; drag points for time and level, and Delete removes them. Fades have a length handle and a curvature handle on the track, and the crossfade (drawn as an X) shows the real curves and has a handle for its shape.

Precision

⇧ makes the drag fine, ⌥ turns off the 0 dB magnet, Esc cancels the gesture, and double-clicking a curvature handle straightens it. One gesture is one Undo step.

How to use it

  1. Pick the Volume tool and double-click the sound.
  2. Drag the point; exact values are in the inspector fields.
  3. Drag the fade handles for length and curvature; right-click picks the shape.
Limits Locked tracks cannot be changed. A crossfade needs enough source material; otherwise it is refused.

F · VISUAL PRESENTATION

Camera, titles
and highlights.

The camera can be arranged over the screen, in a circle or a rectangle. Titles and annotations are drawn straight in the viewer and stay editable objects on the timeline.

The camera overlay

A camera clip can be placed anywhere over the screen, scaled, rotated and made semi-transparent. Circular presenter crops it into a circle, with framing, offset and outline.

Why it is useful

Viewers see you while they follow your screen — the tutorial standard.

How to use it

  1. Select the camera clip.
  2. In Circular presenter choose the corner position, framing and outline.
  3. Fine-tune in Transform.
Result The source stays untouched; you can go back to a rectangle at any time.

Colour and the person’s background

The Colour section (brightness, contrast, saturation) adjusts any video clip or overlay, with a reset to neutral for each value or for the whole section. For a camera clip, Background (person) blurs or removes the background behind the person on camera; the effect is computed on your Mac while editing, shows in the preview and in the export, not in the recorded file, and can be switched off at any time.

Why it is useful

You correct a camera that is too dark or too flat without another app, and what you see in the preview is what gets exported.

How to use it

  1. Select the video clip or overlay.
  2. In the Video tab move the sliders in Colour; double-click a slider to return it to neutral.
  3. For a camera, choose blur or removal in Background (person).
Result The source stays unchanged; each gesture is one Undo step. The person’s background slows the export down.

Effects attached to a clip

A highlight, frame or arrow attaches to a specific clip. Its band appears on the clip, and the inspector controls the selected effect.

Why the target matters

An effect applied to the wrong clip does not show at the intended moment. The button, the drawing and the inspector use the same target, and the timeline clearly shows the targeted clip.

How to use it

  1. Select the target clip.
  2. Pick a shape from the toolbar (rectangle, circle, line, arrow, freehand) and draw in the viewer.
  3. You can also drag an effect over a clip.
Result Several effects can run at the same time, on different clips.

Titles and text styles

Titles have alignment, bold, italic, underline, outline, colour, background, several lines, and appear and disappear effects.

Why it is useful

You mark tutorial steps and feature names without external apps.

How to use it

  1. Press Aa in the toolbar.
  2. Type the text in the viewer.
  3. Choose style and effects in the inspector.
Result An editable title that stays an object on the timeline.

Frame the image in the circle

For Circular presenter, the Frame the image in the circle button shows the whole camera frame faded and draggable; scale it from the corners, and Recentre brings it back to the middle. The circle stays fixed and the picture never leaves gaps inside it. Done confirms, Cancel gives up; the whole gesture is a single Undo step.

Guides are not exported

The faded frame appears only in the preview, never in the exported file. Going back from circle to rectangle does not lose the transforms you made.

Lens

A highlight can have a Lens: the chosen source area is shown magnified in a separate area, with the same proportions. Dimming, blur, outline and shadow act around the magnified area. Magnification interpolates the picture: no new detail appears.

Pointer effects and key commands on screen

For a recording with pointer movement saved, the Pointer tab has three sections. Pointer highlight: an empty Outline (it does not cover what is under the pointer), a soft Halo or a discreet Disc, with colour, size, opacity and outline thickness; the reset button brings back the default look. Click effect: rings that start at the pointer, widen and fade — one ring for a left click, a thin ring with a tinted inside for a right click and two rings for a double click; duration and intensity are under Advanced. Zoom following the pointer stays a separate control. The settings belong to the clip, show at once in the preview and look the same in the export. In addition, if you turned on Settings ▸ Recording ▸ Save keyboard commands, you can show the commands (for example ⌘K) as on-screen keys at the bottom of the picture, in the export too.

Privacy

Everything is off by default and runs only while a recording lasts. While recording, the system sends the app every key press; each is classified on the spot and only combinations with ⌘, ⌃ or ⌥ and function keys are kept — typed text and plain keys are discarded and never reach a file. While a secure field (password) asks for Secure Input, the system sends no keys and nothing is saved. It asks for the system Input Monitoring permission.

How to use it

  1. Turn on the setting you want before recording.
  2. In the editor, select the clip and open the Pointer tab.
  3. Switch on Highlight the pointer or Rings on click, choose the shape and the colour; for keys, Show key commands.
Limits A recording without this metadata has no pointer or key effects; imported clips do not have it. Recordings made before 1.7.0 kept only the primary button: left click and double click are drawn, a right click cannot be told apart.

G · MOTION AND STRUCTURE

Markers, ranges,
animations and transitions.

Markers help you find your way, In/Out sets what is exported, and animations and transitions give the edit its rhythm.

Markers, In/Out and freeze frame

Named markers are visible on the ruler. In and Out set the exported range (the “Only between In and Out” option). Freeze frame extends the image from the cursor.

Why it is useful

You find your way around a long edit and export just a fragment.

How to use it

  1. Put the cursor and use Set In at cursor (and Out).
  2. Press the freeze tool for a still frame.
  3. Export only the range from the export window.
Result An exported fragment with a known duration.

Animations and transitions

Clips, overlays and titles can be animated between two states, with linear, ease-in or ease-out motion; you have multiple keys and easing curves. Between clips you can put a cross dissolve, with explicit length limits. Cutting or freezing keeps exactly what the animation showed before and after.

About the cursor and Foreground Window

Cursor-following zoom and click highlights need metadata recorded during capture: cursor position and clicks, and the foreground window. These are optional and off by default; the keyboard is not read. They cannot be inferred afterwards from an arbitrary video.

Animation keys

Position (X/Y), scale, rotation and opacity are animated with keys. Key at playhead adds a key; each key has its own interpolation to the next one: default, linear, step (the value stays and jumps at the next key), slow in, slow out or smooth. You can move a key in time, jump between keys and edit one property without changing the others.

Cut, trim, duplicate, speed

A cut or a trim does not change what you see: each piece shows exactly what the original showed at the same moment, including the interpolation of the segment the cut fell in. When speed changes, keys keep their relative place in the clip. No key is lost silently.

How to use it

  1. Select the clip, overlay or title.
  2. Move the playhead inside it and press Key at playhead.
  3. Pick the key in the list, change a property and choose the interpolation under From this key.
What can be animated The transform of clips, video overlays and titles is animated, plus fades. Highlights, the pointer, crop and lens have no keys (highlights bound to a clip move with it); Audio Unit effect parameters are not animated.

Animation keys on the track

Under the selected video clip a keyframe band appears, with a diamond for each key (all of them, or only those that change the property chosen in the inspector). Clicking a diamond selects the key and moves the playhead there, dragging moves it in time, and double-clicking the band adds a key.

Precision

⇧ makes the drag fine, Esc cancels it, Delete removes the selected key, and right-click offers the interpolation or deletion. Exact values stay in the inspector.

How to use it

  1. Select the video clip.
  2. Double-click the key band to add a key.
  3. Drag the diamond for time; change the values in the inspector.
Limits A key holds the five placement properties together; “changes the property” means its value differs from the previous key’s.

H · EXPORT AND KEEPING THE PROJECT

A clear export.
A project that is never lost.

Export has a simple mode with presets and an advanced mode with controls for size, frame rate, codec and quality. The summary in the window describes exactly the file you will get.

Simple export

Pick the preset, the resolution (Original, 720p, 1080p, 1440p, 4K or your own values), the quality (Compact, Balanced, High, Maximum), the range (whole project or only between In and Out) and the name. The web presets write MP4 files. The summary shows the resulting size, frame rate, codec, a size estimate and the sound.

Why it is useful

You get a good file without knowing technical terms. The default name contains the project name and the date.

How to use it

  1. Press Export.
  2. Choose preset and destination.
  3. Press Export in the window.
Result A video file in the chosen folder. The destination is protected, and a cancelled export leaves no partial files.

Advanced export

Controls for resolution (including 4K and custom values), frame rate, format (MP4 or QuickTime), codec (H.264, HEVC), keyframes, audio rate and channels (stereo or mono). The Encoding row says whether the export uses the Mac’s hardware encoder (checked before the export); multi-pass encoding does not exist in the system encoder, so it is not offered. Control sets how the video size is decided: Quality (constant quality, the default: a steady look at the smallest size the content allows), Average rate in Mb/s or Target size in MB (a one-pass estimate: the file usually lands a few percent under the target, it is not a guarantee). The Tutorial / screen recording preset (H.264, quality High, keyframes every 5 s) keeps small text readable in a small file. Presets can be saved.

Copy without processing vs re-encode

Copy without re-encoding keeps source quality, but is refused when the project requires processing (for example titles, effects or mixing) — it never degrades silently. Processed and compressed re-encodes with loss. There are also ProRes master and lossless frame sequence + WAV.

How to use it

  1. Switch to Advanced.
  2. Pick the mode, then size, frame rate and codec.
  3. Check the summary at the bottom before exporting.
Result The file has the size, frame rate and codec in the summary; in Quality mode the summary gives a size range (an estimate that depends on the content), not an exact value. Size and range are checked after export.

Archiving the project and moving it

Archive: project + media makes a self-contained copy with relative paths, so it opens anywhere and finds its media even if the folder is moved. The originals do not change. If media is missing, archiving refuses and says what is missing; a missing clip can be relinked with Relink file…. A stopped archive leaves no partial archive.

J · FAQ AND SUPPORT

Short answers,
limits stated openly.

If you do not find the answer here, open the manual or write to us on the project page.

What permissions does SADROG ask for, and why?

Screen Recording to capture, Microphone for microphone sound and Camera for the camera. The last two are requested only when you add such a source. The keyboard is not read.

A source is missing (camera, microphone, display). What do I do?

Check in Permissions that access is granted and the device is connected. Then add it from the Add source menu. Test sources marked SIMULATION appear only in the verification build.

I moved the project’s media. What happens?

The project marks its missing files; use Relink file… to point to them again. For a project that must travel, create an archive with media: it opens anywhere.

Why can’t I copy without processing?

Copying without re-encoding requires that the project needs no processing. Titles, effects or mixing make it impossible, and SADROG refuses instead of silently degrading quality. Choose “Processed and compressed” or ProRes.

How does SADROG update?

From the app: Check for updates…, or download the latest file from this page. Updates install without deleting your projects.

What data is sent at activation?

Name and e-mail for the reply, the computer name (optional), the option chosen, language, version and the Mac’s identifier. No recordings, projects or captures are sent.

Where do I find the diagnostic log?

SADROG writes a local log at ~/Library/Logs/SADROG.log (no passwords or file contents). You can attach the file when asking for support.

What are the current limits?

It runs only on Apple Silicon and macOS 15+. Cursor and foreground window are recorded only if you enable the option before capture. The Audio Unit plug-in library depends on the plug-ins you installed. Features announced for the future are not presented here as existing.

Where do I ask for support?

On the project page: github.com/gordasgdc/sadrog/issues. For activation, from the app (WhatsApp or e-mail buttons).
