Cerințe

macOS 26.0 sau mai nou (minimul declarat de build) · proba efectivă: macOS 27.0.1 cu DaVinci Resolve Studio 21.2 · Mac cu Apple Silicon · DaVinci Resolve Studio.

Instalare

1. Descarcă pachetul și deschide-l cu dublu-clic.
2. Urmează pașii instalatorului (cere parola Mac-ului tău).
3. Repornește DaVinci Resolve, apoi alege în Deliver: Format → GDC QuickTime, GDC MP4 sau GDC Matroska, apoi Codec → GDC Encoder și Type → varianta dorită (de exemplu GDC H.265 Software x265).

Sursă deschisă și contribuții

Codul sursă este public: github.com/gordasgdc/gdc-resolve-encoder. Codul pluginului este sub licență MIT; pachetul pentru Mac include FFmpeg, x264 și x265 și se distribuie sub GPLv3, cu textele licențelor și oferta de sursă în pachet. Proiectul primește contribuții prin Issues și Pull Requests, mai ales pentru Windows.

Windows

Windows — ediție gratuită v1.7.1 (întreținere), fără activare. Stare reală: sursa este pregătită și pachetul urmează să fie construit în CI, dar proba încărcării și a exportului cu imagine și sunet în DaVinci Resolve Studio pe Windows încă lipsește: nu mai am un sistem Windows disponibil pentru verificări. Descărcarea gratuită apare aici imediat ce pachetul este publicat. Dezvoltarea de funcții noi pentru Windows este suspendată; contribuțiile, inclusiv proba pe Windows, sunt binevenite.

Descărcare Windows v1.7.1 — în așteptarea probei

Versiunea 1.7.1 · gdc-resolve-encoder-1.7.1-windows-x64.zip · arhivă .zip · Windows 10/11, 64-bit

Instalare Windows (v1.7.1)

1. Dezarhivează fișierul.
2. Rulează install.bat cu dublu-clic: copiază folderul gdc_resolve_encoder.dvcp.bundle în %ProgramData%\Blackmagic Design\DaVinci Resolve\Support\IOPlugins\ și cere singur drepturi de administrator.
3. Repornește DaVinci Resolve Studio.

Condiții de utilizare pentru v1.7.1

Gratuit, fără cont, perioadă de probă, cod de activare sau donație obligatorie; pluginul nu contactează niciun server. Pornește de la v1.7.0 cu codul de licență eliminat, fără funcții noi.

Versiunea istorică v1.7.0 rămâne în arhiva release-urilor, dar cere un cod de activare: nu este ediția fără activare și nu este oferită ca descărcare aici.
