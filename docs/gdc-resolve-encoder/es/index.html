Resumen de las comprobaciones de la edición 1.8.0, en un Mac con Apple Silicon.

Imagen

La comparación con el original solo muestra diferencias de compresión, sin cambios de color ni fotogramas saltados.

Sonido

El audio PCM se escribe sin cambios. Solo difieren los pocos milisegundos de fundido que Resolve aplica en los bordes de los clips.

Reimportación

Los archivos se reabren en Resolve y en FFmpeg sin errores.

QUÉ ES Y QUÉ NO ES

Un plugin independiente.
No un producto de Blackmagic.

Funciona con DaVinci Resolve Studio; la versión gratuita no carga plugins de exportación. El plugin se ejecuta en local y no envía datos a ninguna parte.

Windows no forma parte de la edición 1.8.0: la última versión de Windows publicada es v1.7.0 (véase Descarga). El desarrollo para Windows está suspendido; se aceptan contribuciones.

GDC Resolve Encoder es un proyecto independiente. No está desarrollado, aprobado ni respaldado por Blackmagic Design. DaVinci Resolve es una marca de su titular.

Requisitos

macOS 26 o posterior (el mínimo declarado por el build; verificado en macOS 27) · Mac con Apple Silicon · DaVinci Resolve Studio.

Instalación

1. Descarga el paquete y ábrelo con doble clic.
2. Sigue el instalador (pide la contraseña de tu Mac).
3. Reinicia DaVinci Resolve y, en Deliver, elige Format → GDC QuickTime, GDC MP4 o GDC Matroska y luego Codec → GDC Encoder y Type → la variante deseada (por ejemplo GDC H.265 Software x265).

Código abierto y contribuciones

El código fuente es público: github.com/gordasgdc/gdc-resolve-encoder. El código del plugin tiene licencia MIT; el paquete para Mac incluye FFmpeg, x264 y x265 y se distribuye bajo GPLv3, con los textos de licencia y la oferta de código fuente dentro del paquete. Se aceptan contribuciones mediante Issues y Pull Requests, sobre todo para Windows.

Windows

Windows — última versión estable publicada: v1.7.0. El desarrollo y las pruebas para Windows están suspendidos porque ya no dispongo de un sistema Windows para verificar. La versión existente sigue disponible para descargar. Se agradecen las contribuciones para continuar el soporte de Windows.

Instalación en Windows (v1.7.0)

1. Descomprime el archivo.
2. Ejecuta install.bat con doble clic: copia la carpeta gdc_resolve_encoder.dvcp.bundle a %ProgramData%\Blackmagic Design\DaVinci Resolve\Support\IOPlugins\ y pide por sí mismo permisos de administrador.
3. Reinicia DaVinci Resolve (Studio). La codificación por hardware NVENC requiere una tarjeta NVIDIA con un controlador actual.

Condiciones de uso de v1.7.0

La versión de Windows v1.7.0 conserva las condiciones de esa versión, distintas de la edición gratuita para macOS: requiere un código de activación vinculado al Machine ID del ordenador, y el apoyo al proyecto se hace únicamente como donación. Los términos y la guía PDF dentro del archivo describen esas condiciones. La edición 1.8.0 para macOS no pide activación, cuenta, periodo de prueba ni donación.

Estado

Edición gratuita para macOS. Puede haber límites; puedes comunicarlos en la página del proyecto.
